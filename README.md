# 📊 Mini AI-Powered EDA App

An interactive **AI-powered Exploratory Data Analysis (EDA) web application** built with Python and Streamlit.

## ✨ Features

* 📁 Upload and analyze datasets
* 🔍 Dataset overview and data inspection
* 🧹 Missing value analysis
* 📊 Statistical analysis
* 🔗 Correlation analysis
* 📈 Data distribution visualization
* 🤖 AI-powered Pandas Assistant

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* Generative AI
